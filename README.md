# network-security-threats
A cybersecurity research project focused on understanding common network security threats, their attack mechanisms, real-world impact, and mitigation strategies.

## 📌 About the Project

This project researches major network security threats that can affect individuals, organizations, systems, and network infrastructure.

The report explains how each attack works, provides documented real-world examples, analyzes the potential impact, and presents practical security measures for prevention and mitigation.

## 🔐 Threats Covered

* DoS / DDoS Attacks
* Man-in-the-Middle (MITM) Attacks
* IP Spoofing
* DNS Poisoning / DNS Spoofing

## 📋 Research Areas

For each threat, the research covers:

* How the attack works
* Attack vector
* Real-world example
* Security impact
* Mitigation strategies
* Prevention techniques

A comparison table is also provided to analyze the threats based on attack vector, risk level, execution difficulty, and ease of mitigation.

## 🎯 Objective

To develop a practical understanding of common network security threats and identify effective defensive techniques that can help network administrators protect systems, users, and network infrastructure.
